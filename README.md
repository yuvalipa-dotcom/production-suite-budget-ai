# production-suite-budget-ai

> **ALL DATA IN THIS REPOSITORY IS SYNTHETIC.** It is generated by a seeded,
> documented simulation and contains no real customer, vendor or event data.
> Results on this data are not evidence of real-world predictive accuracy.

An academic project for *AI Development & Collaboration: Industry-Simulated AI
Product Workflow*. The business problem is **predicting budget overruns for event
productions**: will a production exceed its client-approved budget, with what
probability, and by how much (signed, in ILS)?

This repository is separate from any commercial product codebase. It contains
only original code, synthetic data and documentation.

```
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m generator.cli --version v2 --out data/synthetic/v2
.venv\Scripts\python -m pytest
```

The generated files are byte-identical for seed `42`. A test checks the committed dataset against a fresh generation.

## The dataset (seed 42, active version v2)

**The versioned synthetic dataset under `data/synthetic/` is committed intentionally as the project's source data.** It is regenerable byte-for-byte from the seed, and a test checks the committed copy against a fresh generation. `v1` is kept frozen for traceability; `v2` is active ([`docs/target_audit.md`](docs/target_audit.md)).

| | |
|---|---|
| Productions | **400** (4 archetypes × 100) |
| Snapshots per production | **4** (S0 contract · S1 35% of lead time · S2 65% · S3 14 days before the event) |
| Snapshot rows | **1,600** |
| Split (by production) | train 280 · test 80 · demo 40 (1,120 / 320 / 160 rows) |
| CV folds | 5, on train only, grouped by production |
| Overrun rate | 47.2% of snapshots |

## Target

```
budget_gap_ils = final_cost_pre_vat + (contractual fee, if included in the budget) − approved budget   (pre-VAT, signed)
is_overrun     = budget_gap_ils > 0.5   (any positive excess; 0.5 is rounding tolerance only)
```

- A 2% materiality level exists only as a warning flag.
- A later fee concession changes company profit, never the overrun label.
